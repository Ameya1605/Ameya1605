# 💫 About Me:
Hey, I'm Ameya 👋<br><br>I'm a Computer Science Engineering student and software developer who enjoys going beyond simply making things work. I'm interested in understanding why they work, what happens underneath, and how they can be made better.<br><br>My interests sit across software engineering, systems, algorithms, artificial intelligence, and computer science fundamentals. I enjoy moving between different levels of abstraction — from designing an application or API to understanding memory, processes, filesystems, networks, databases, and the algorithms underneath them.<br><br>🧠 What I'm Into :-<br><br> -> Software Engineering — writing practical, maintainable software and understanding the engineering decisions behind it.<br> -> Systems & Linux — operating systems, filesystems, processes, networking, low-level programming and the things that happen beneath the application layer.<br> -> Algorithms & Problem Solving — DSA, competitive programming, mathematical reasoning and breaking complicated problems into manageable pieces.<br> -> Artificial Intelligence — LLMs, RAG, information retrieval, embeddings, reranking and building useful AI-powered systems.<br> -> Computer Science Fundamentals — OS, DBMS, Computer Networks, Compilers, Computer Architecture, Discrete Mathematics and the theory that makes everything else possible.<br> -> Development — building with C++, Python, JavaScript/TypeScript and modern web technologies.<br><br>🔬 How I Approach Technology :-<br><br>I don't like treating technology as a collection of tools to memorize.<br><br>If I use something, I want to eventually understand what's happening behind it.<br><br>If an abstraction hides something interesting, I want to know what's underneath it.<br>If something breaks, I want to know why it broke.<br>If a solution works, I want to know whether there's a better way to do it.<br><br>That's what keeps me interested in Computer Science.<br><br>⚙️ Currently,<br><br>I'm continuously working on strengthening my CS fundamentals, problem-solving ability and software engineering skills, while preparing for the next stage of my career.<br><br>Right now, a lot of my learning revolves around:<br><br>C++ • Python • Linux • DSA • Systems • AI • Databases • Networks • Algorithms
